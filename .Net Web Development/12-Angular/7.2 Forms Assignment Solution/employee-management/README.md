# Employee and Department Forms Application

This project is an Angular application that demonstrates how to create an Employee Form using the template-driven method and a Department Form using the reactive forms method. 

## Project Setup Instructions

### Step 1: Set Up Angular Project
1. Install Angular CLI if it's not already installed.
2. Create a new Angular project named **"employee-department-app."**
3. Navigate into the project directory.

### Step 2: Create Components
1. Generate two components:
   - One for the **Employee Form**
   - One for the **Department Form**
2. Ensure you have the main **App** component.

### Step 3: Set Up Employee Form (Template-Driven)
1. In the Employee Form component, create a form with the following fields:
   - **Employee Name**
   - **Employee Age**
   - **Employee Email**
2. Add a submit button to the form.
3. After submission, display the entered employee details on the page.

### Step 4: Set Up Department Form (Reactive Forms)
1. In the Department Form component, create a reactive form with these fields:
   - **Department Name**
   - **Department Head**
   - **Budget**
2. Add a submit button to the form.
3. After submission, display the entered department details on the page.

### Step 5: Include Components in the App Component
1. In the main App component, include both the Employee Form and Department Form components.

### Step 6: Add Necessary Modules
1. Make sure to import the necessary modules for template-driven and reactive forms in the App module.

### Step 7: Run the Application
1. Start the development server.
2. Open your web browser and navigate to the provided local address to see your application in action.

## Conclusion
Your application should now have two working forms. The Employee Form collects and displays employee information, while the Department Form does the same for department details. 

You are encouraged to style your forms and explore form validation techniques to enhance user experience.
